# VALLEY Roleplay Website

React + Vite public community website.

## Development
- npm install
- npm run dev
- npm run build

## GitHub Pages
Set Pages source to **GitHub Actions**. The workflow in .github/workflows/deploy.yml builds and deploys the site.

Public pages: Home, Rules, Announcements, About, and Links. The admin/CMS is intentionally deferred until the Supabase phase. This public build has no staff login or admin dashboard.
